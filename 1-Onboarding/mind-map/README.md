# Onboarding mind map

An interactive map of every assignment in the Onboarding module (weeks 1-3): preparation, lesson-plan exercises, the repositories they use, and the Module-Onboarding coursework issues.

- Hover a node to see a short summary of what to do.
- Click a node to open the exact section, issue or repository on GitHub.
- Search, expand/collapse branches and zoom from the toolbar.

**Open it:** https://hackyourfuturebelgium.github.io/Intro-to-Programming/1-Onboarding/mind-map/

(Requires GitHub Pages to be enabled for this repository: Settings → Pages → Deploy from a branch → `main` / root.)

## Updating

`index.html` is self-contained: the map data is the `TREE` object near the top of the `<script>`. Each node has a title (`t`), kind (`k`), link (`u`), summary (`s`) and children (`c`). Edit it when the curriculum or the Module-Onboarding issues change.
